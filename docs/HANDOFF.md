# Передача работы

Для следующего, кто продолжит проект (человек или Viktor). Читать после `AGENTS.md`.

## Состояние

Версия 0.2.0. Работают все 8 шагов гайда, бонус и доработки 1–8 из списка менеджера (камера, воспроизведение,
аккаунты, «Поделиться», профиль, поиск, входящие, тесты/CI). Не сделан переключатель языка (доработка 9).
Подробная таблица — [GUIDE-MAPPING.md](GUIDE-MAPPING.md).

Репозиторий: https://github.com/nurymyn/Loopa (публичный).

## Что проверено, а что нет

Проверено (в Linux-песочнице без Docker и без телефона):

- сервер: `tsc --noEmit`, `npm run build`, миграции 001–002 на PostgreSQL 16.15, `seed`, 20 тестов API — все
  проходят; повторено на «чистом клоне» (свежая база, `npm ci`, ролики не скачаны,
  `SEED_ALLOW_MISSING_MEDIA=true`) — так же, как в CI;
- ручные запросы `curl`: регистрация, вход, неверный пароль, загрузка видео (multipart) и его место в ленте,
  лайк и комментарий от второго пользователя во «Входящих» первого, хэштег, страница `/v/:id` с Open Graph;
- приложение: `npm ci` + `tsc --noEmit` на чистой копии, `npx expo-doctor` (20/20),
  `npx expo export --platform android` и `--platform web` собираются;
- веб-сборка открыта в headless Chromium (390×844) с настоящим API: вход, лента (видео играет), комментарии,
  меню «Поделиться», профиль, входящие, друзья, хэштег, поиск, интересы, публикация — см. `docs/screenshots/`;
- `npm run media` скачал и обработал все 10 роликов.

Не проверено:

- запуск в Expo Go на iPhone/Android: свайпы, вибрация, камера (`expo-camera`), галерея, загрузка с телефона,
  системное меню «Поделиться», expo-secure-store, вырезы экрана;
- `docker compose up` и Docker-образ API — Docker в песочнице недоступен (PostgreSQL запускали из бинарников
  пакета `@embedded-postgres/linux-x64`);
- GitHub Actions: CI проходит на main (jobs server и mobile, 2026-11-03).

## Команды

```bash
git clone https://github.com/nurymyn/Loopa.git && cd Loopa
npm run setup                     # зависимости server/ и mobile/
docker compose up -d              # PostgreSQL 16 на :5432 (loopa/loopa/loopa)
npm run media                     # 10 роликов с Mixkit в media/ (нужен ffmpeg)
npm run migrate && npm run seed   # схема + демо-данные (seed СТИРАЕТ базу)
npm run dev                       # API на :4000, проверка: curl localhost:4000/health
cd mobile && npx expo start       # QR для Expo Go; --tunnel, если телефон в другой сети
npm test                          # из корня: тесты API (после migrate + seed)
npm run typecheck                 # сервер + приложение
```

Без Docker: любой PostgreSQL 16 и `DATABASE_URL` в `server/.env` (пример — `server/.env.example`).
Демо-вход: ник `demo`, пароль `loopa-demo` (у всех демо-аккаунтов, только для разработки) или кнопка
«Войти как демо». Для `curl`: `-H 'Authorization: Bearer demo-token'`.

## Что упрощено или заглушено

- Рекомендации — формула в `server/src/lib/recommend.ts`, без ML.
- Нет модерации, жалоб, блокировок, приватных аккаунтов.
- Токены не истекают, нет сброса пароля, нет ограничения частоты запросов (rate limit) на вход.
- Видео не перекодируются: файл хранится как прислали. Превью — только если на сервере есть ffmpeg (в Docker-образе есть).
- Файлы на локальном диске (`server/uploads/`), не в облаке.
- `loopa://video/:id` на странице `/v/:id` работает только в отдельной сборке, не в Expo Go.
- «Поделиться профилем» отправляет текст с ником, веб-страницы профиля нет.
- Тексты интерфейса — прямо в экранах, только русский.

## Известные проблемы

1. Курсор «Для вас» хранит id всех показанных видео (до 500) — при большой базе он станет длинным. Нужен
   серверный кэш сессии ленты или другой подход.
2. Поиск — подстрока (`ILIKE`): «еда» находит «соседа». Для русского языка нужен полнотекстовый поиск
   или поиск по началу слова.
3. Вкладки профиля и списки подписчиков используют offset-курсор: если список меняется между страницами,
   элемент может повториться или пропасть. Лента «Подписки», комментарии и входящие — keyset, там проблемы нет.
4. Если запустить `expo start --tunnel`, адрес API автоматически не определяется — нужен `EXPO_PUBLIC_API_URL`.
5. В веб-сборке (`expo start --web`) камера и галерея работают ограниченно; веб — только для просмотра и скриншотов.
6. `npm audit` показывает предупреждения в зависимостях Expo (транзитивные, не в нашем коде) — не разбирались.

## Следующие задачи по приоритету

### 1. Проверка на телефонах и исправления

Запустить на одном iPhone и одном Android через Expo Go, пройти чек-лист: свайп ленты, двойной тап,
вибрация, шторка комментариев свайпом, камера (запись, смена камеры, вспышка, таймер), галерея, публикация,
«Поделиться», «Скопировать ссылку», фото профиля, вход/выход, два телефона под разными аккаунтами.

Готово, когда: каждый пункт отмечен в `docs/DEVICE-CHECK.md` (устройство, версия ОС, результат), найденные
ошибки исправлены или записаны в «Известные проблемы».

### 2. Тексты интерфейса в одном месте + язык ru / kk / en (доработка 9)

Вынести все строки из `mobile/src` в `mobile/src/i18n/` (`ru.ts` — основной, `kk.ts`, `en.ts`), функция `t()`
и выбор языка в «Изменить профиль», выбор хранится в `storage`. Без новых библиотек, если хватит своей функции.

Готово, когда: `rg -n "[А-Яа-яЁё]" mobile/src --glob '!**/i18n/**'` ничего не находит (кроме комментариев),
переключение языка меняет все экраны без перезапуска, `npm run typecheck` проходит, все ключи есть во всех трёх
языках (проверка типом: `kk` и `en` имеют тип `typeof ru`).

### 3. Безопасность аккаунтов

Срок жизни токенов (например, 30 дней с продлением по `last_used_at`), выход со всех устройств, ограничение
попыток входа (например, 10 в минуту на ник и на IP), смена пароля.

Готово, когда: новая миграция `003_…`, тесты на истёкший токен (401), на 11-ю попытку входа (429) и на смену
пароля; `DEV_AUTH=false` по умолчанию в `docker-compose.yml` для профиля `api`.

### 4. Обработка видео при загрузке

На сервере после загрузки: перекодировать в H.264 720p, обрезать до 60 с, сделать превью; пока идёт обработка —
статус `processing` и видео не показывается в лентах. Проверять, что файл действительно видео (ffprobe), а не
только расширение.

Готово, когда: колонка `status` в миграции, тест «загрузка не-видео → 400», тест «видео в обработке не попадает
в ленту», загруженный с iPhone `.mov` воспроизводится на Android.

### 5. Деплой для показа друзьям

API + PostgreSQL на сервере (например, VPS с `docker compose --profile api`), HTTPS, `PUBLIC_BASE_URL`,
`DEV_AUTH=false`, сборка APK через EAS Build с `EXPO_PUBLIC_API_URL` на этот сервер.

Готово, когда: в `docs/DEPLOY.md` пошаговая инструкция, APK ставится на Android-телефон и работает без компьютера,
страница `/v/:id` открывается по HTTPS и показывает превью в Telegram.
