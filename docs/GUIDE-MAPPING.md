# Соответствие гайду «Свой TikTok за 8 шагов»

Статусы: **готово** — сделано и проверено, насколько можно без телефона (см. «Как проверено»);
**частично** — сделано не всё, что просит шаг; **заглушка** — экран есть, функции нет.

Важно: приложение ни разу не запускалось на настоящем телефоне или эмуляторе — в среде, где его собирали,
их нет. Проверено: типы (`tsc`), сборка бандлов Android и веб (`expo export`), `expo-doctor`, работа экранов
в веб-сборке в headless Chromium (скриншоты в `docs/screenshots/`), API — тестами на настоящем PostgreSQL.
Жесты, вибрация, камера, галерея и системное меню «Поделиться» на телефоне не проверены.
