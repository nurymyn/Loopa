# Архитектура Loopa

Три части: приложение на Expo (`mobile/`), API на Fastify (`server/`) и PostgreSQL. Приложение ничего не хранит
у себя, кроме токена входа, флага «звук выключен» и недавних поисков (expo-secure-store; в веб-сборке —
localStorage). Всё остальное — в базе.

## Сервер

`server/src/app.ts` собирает Fastify: CORS, multipart (загрузки), раздача файлов, авторизация, маршруты.

| Файл | Что внутри |
|---|---|
| `src/config.ts` | Настройки из переменных окружения (см. `server/.env.example`) |
| `src/db.ts` | Пул соединений `pg`, `withTransaction()` |
| `src/auth.ts` | Читает `Authorization: Bearer`, ищет SHA-256 токена в `auth_tokens`, кладёт `req.userId` |
| `src/routes/auth.ts` | Регистрация, вход, выход, демо-вход, `/me`, фото профиля |
| `src/routes/feed.ts` | Ленты «Для вас» и «Подписки», `/me/interests` |
| `src/routes/videos.ts` | Видео, лайки, избранное, репосты, «поделиться», просмотры |
| `src/routes/comments.ts` | Комментарии, ответы, лайки комментариев |
| `src/routes/users.ts` | Профили, вкладки профиля, подписчики, подписки, follow |
| `src/routes/social.ts` | Друзья, входящие, счётчик непрочитанного |
| `src/routes/discover.ts` | Поиск, страница хэштега, страница звука |
| `src/routes/upload.ts` | Публикация видео (multipart) |
| `src/routes/share.ts` | `/v/:id` — HTML-страница видео с Open Graph |
| `src/lib/recommend.ts` | Алгоритм «Для вас» и профиль интересов |
| `src/lib/videos.ts` | Общий SELECT для видео и перевод строки базы в JSON |
| `src/lib/notify.ts` | Создание и отзыв уведомлений |
| `src/lib/passwords.ts` | scrypt-хэши паролей, генерация и хэширование токенов |

Ошибки: обработчики бросают `HttpError` (`src/lib/errors.ts`), общий обработчик превращает их в
`{ "error": "текст" }` с нужным статусом. Всё неожиданное — 500 без подробностей наружу, подробности в лог.

### Авторизация

- Регистрация: ник `^[a-z0-9._]{2,30}$`, пароль от 6 символов. Пароль хранится как
  `scrypt$N$соль$хэш` (`node:crypto`, N=16384). Проверка через `timingSafeEqual`.
- Вход выдаёт случайный токен (32 байта, base64url). В базе лежит только SHA-256 токена, так что утечка таблицы
  `auth_tokens` не даёт войти. Выход удаляет токен. Срока жизни у токенов пока нет.
- Демо-вход (`POST /api/auth/dev-login {handle}`) выдаёт токен без пароля любому существующему нику. Включён,
  пока `DEV_AUTH=true`. На публичном сервере его надо выключить.

### Лента «Для вас»

`src/lib/recommend.ts`, функция `rankForYou`:

1. **Интересы.** Для каждого тега: `3 × лайки видео с этим тегом + 1 × видео с этим тегом, досмотренные до
   конца`. Делим на максимум, получаем вес 0..1.
2. **Оценка видео:** `интерес × 1.0 + популярность × 0.3 + свежесть × 0.2 − 0.5, если уже досмотрено`.
   Популярность — `log10(лайки + 1) / 7`, свежесть — `exp(−возраст_в_днях / 14)`.
3. **Сборка страницы.** Каждое место: с вероятностью 20% — случайное ещё не показанное видео (`explore`),
   иначе лучшее по оценке (`interest` или `popular`).
4. Свои видео, загруженные за последние 15 минут, ставятся первыми на первой странице (`yours`) —
   так новое видео сразу видно в ленте.

Курсор хранит зерно генератора случайных чисел и id уже показанных видео: одна и та же страница по одному
курсору всегда одинаковая. Когда показаны все видео, начинается новый круг — лента бесконечная.
У каждого видео в ответе есть `recommendation.reason` и `score`, чтобы было видно, почему оно попало в ленту.

Скрытый экран интересов (`mobile/src/app/interests.tsx`, тройной тап по логотипу) показывает те же числа,
что `GET /api/me/interests`.

### Лента «Подписки»

Видео авторов, на которых вы подписаны, новые сверху. Курсор — пара `(created_at, id)` последнего видео
(keyset-пагинация): новые видео не сдвигают страницы.

### Лайки, избранное, репосты, просмотры

Это отдельные таблицы (`likes`, `saves`, `reposts`, `views`, `shares`). Повторный лайк ничего не меняет
(`ON CONFLICT DO NOTHING`). Счётчики в `videos` двигают триггеры (`bump_video_counter`), поэтому ленте не нужен
`COUNT(*)`. `share_count` = отправленные ссылки + репосты.

Просмотр: приложение отправляет одну запись на «визит» — когда видео уходит с экрана — с временем просмотра
и флагом «досмотрено до конца хотя бы раз». Визиты короче секунды не отправляются.

### Комментарии

Один уровень ответов (`parent_id`). Верхние комментарии — новые сверху, keyset-курсор. Ответы — по порядку,
до 100 штук. Лайки комментариев — таблица `comment_likes`, счётчик в `comments.like_count` через триггер.

### Подписки и уведомления

`notify()` пишет уведомление в той же транзакции, что и само действие: лайк, комментарий, ответ, подписка,
репост. Себе уведомления не создаются. Если действие отменили (снят лайк, отписка, отменён репост),
уведомление удаляется — чтобы десять нажатий не превратились в десять строк во «Входящих».
Счётчик непрочитанного — `GET /api/inbox/unread`, приложение опрашивает его раз в 30 секунд и при возврате
в приложение; открытие вкладки «Входящие» вызывает `POST /api/inbox/read`.

### Файлы

- `media/` — демо-ролики, раздаются по `/media/seed/...`. В git их нет, их скачивает `npm run media`.
- `server/uploads/` — загруженные видео и фото профиля, раздаются по `/media/uploads/...`.
- В базе хранится относительный путь (`seed/01-donuts.mp4`, `uploads/<uuid>.mp4`). Полный адрес собирается
  из `PUBLIC_BASE_URL` или, если он не задан, из адреса запроса — поэтому телефон в той же сети получает
  ссылки с IP компьютера.
- Загрузка видео: до `MAX_UPLOAD_MB` (50 МБ), `.mp4/.mov/.m4v/.webm`. Если на сервере есть ffmpeg, берётся
  длительность и делается превью. Хэштеги из подписи, совпадающие с тегами (`#еда`, `#юмор`, …), становятся
  тегами видео для «Для вас».

## Приложение

Навигация — expo-router, файл в `mobile/src/app/` = экран.

| Экран | Файл |
|---|---|
| Корень: сессия, вход, стек экранов | `src/app/_layout.tsx` |
| Нижнее меню | `src/app/(tabs)/_layout.tsx` + `src/components/TabBar.tsx` |
| Лента | `src/app/(tabs)/index.tsx` + `components/VideoFeed.tsx`, `VideoItem.tsx` |
| Друзья, Входящие, Мой профиль | `src/app/(tabs)/friends.tsx`, `inbox.tsx`, `profile.tsx` |
| Камера, публикация | `src/app/record.tsx`, `src/app/publish.tsx` |
| Чужой профиль, подписчики | `src/app/user/[handle].tsx`, `src/app/people/[handle].tsx` |
| Видео из сетки | `src/app/video/[id].tsx` |
| Поиск, хэштег, звук | `src/app/search.tsx`, `hashtag/[tag].tsx`, `sound.tsx` |
| Интересы, правка профиля | `src/app/interests.tsx`, `edit-profile.tsx` |

Главное в ленте (`VideoFeed` + `VideoItem`):

- `FlatList` с `pagingEnabled`, высота элемента = высота области ленты.
- Плеер (`expo-video`) создаётся только для видимого видео и соседей (±1) — следующее уже буферизуется.
- Играть можно, только если видео на экране, вкладка в фокусе, приложение не свёрнуто и не открыта шторка
  комментариев или «Поделиться».
- Действия обновляют список сразу (оптимистично) и откатываются, если сервер ответил ошибкой.

`src/lib/session.tsx` хранит пользователя, токен (expo-secure-store), флаг звука, счётчик непрочитанного и
только что опубликованное видео. `src/lib/api.ts` — все запросы к серверу, таймаут 10 секунд; сетевая ошибка
превращается в понятный текст через `describeError()`. Адрес сервера: `EXPO_PUBLIC_API_URL` или, если он пуст,
IP компьютера, на котором запущен `expo start`, порт 4000.

## Как добавить эндпоинт

1. Если нужны новые таблицы или колонки — новая миграция `server/migrations/00N_что_делает.sql`.
   Старые миграции не редактировать.
2. Маршрут — в подходящий файл `server/src/routes/` или новый файл, зарегистрированный в `src/app.ts`
   внутри блока с префиксом `/api`. Пользователь — `requireUser(req)`, ошибки — `badRequest()`, `notFound()`.
   Видео отдавать через `queryVideos()` / `videosByIds()`, людей — через `PERSON_SELECT` / `toPerson()`.
3. Тест в `server/test/api.test.ts`.
4. Метод в `mobile/src/lib/api.ts`, типы в `mobile/src/lib/types.ts`.
5. Строку в таблицу API в `README.md`.

## Как добавить экран

1. Файл в `mobile/src/app/` (например, `settings.tsx` → путь `/settings`).
2. Если экран открывается поверх (модально) — описать его в `src/app/_layout.tsx`.
3. Цвета и отступы — только из `src/theme.ts`. Загрузка — компоненты из `components/Skeleton.tsx`,
   ошибки — `ErrorState`, пустые списки — `EmptyState`. Верхний отступ — `useSafeAreaInsets()`.
4. Списки — `usePaged()` из `src/lib/usePaged.ts` (обновление и подгрузка уже внутри).
5. `npm run typecheck` в `mobile/`.
